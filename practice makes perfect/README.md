# practice makes perfect - Information Script

## About
This is my practice makes perfect CMD project. I created a Windows batchscript that displays basic information about my computer.

##what the script displays 
- Username
- Computer name
- Windows version
- Curtrent date
- current time
- Files and folders in the directory
